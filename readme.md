# Dinesh Kumar — Frontend Architect Portfolio

A colorful, motion-led React portfolio for Dinesh Kumar. The experience combines a fluid pointer reveal, GSAP ScrollTrigger choreography, and expressive editorial layouts built with responsive CSS.

## Run locally

```bash
npm install
npm run dev
```

Create an optimized production build with:

```bash
npm run build
npm run preview
```

## Stack

- React 19 + Vite 8
- GSAP and ScrollTrigger
- Responsive CSS with reduced-motion and touch fallbacks

Profile content is centralized in `src/data/portfolio.js`. Public career details were cross-checked against Dinesh's LinkedIn profile and personal site; unverified employers, metrics, and social profiles are intentionally omitted.
